# P1 判定规则

P1 是修订优先级，不是产品质量评级。判断顺序是“证据是否明确 → 是否影响采购或实际使用 → 是否存在可解释的版本差异”。

| 情况 | 处理 |
| --- | --- |
| 同名有效长度在首屏为 43 mm、正文为 31.8 mm，未区分测量位置 | 可列 P1，建议核对图纸；不要自行判定其中哪个数值正确 |
| 5 g × 4 标为 60 g，且没有其他分块说明 | 算术冲突可列 P1；核对每块、每条和组合数量 |
| 总长 43 mm、有效长 31.8 mm | 测量口径不同，不能仅凭数值不同判错 |
| 0.453 英寸与行业公称孔径数值存在取整差异 | 先查公称值、允许公差及厂家表达；数学差异不自动等于适配错误 |
| 不同段落分别要求螺母固定和橡胶拉入，指向同一结构 | 核对图片/结构，确认矛盾且影响安装时可列 P1 |
| 单位是每条总重，一处被写成单块重量 | 影响订货理解，可列 P1，保留原文和实际组合 |
| SKU、车型、传感器接口来自另一产品模板 | 确认该段描述本产品，而非对比介绍后，列出实质错配 |
| 图中两块、参数三块 | 排除变体图、示意图、遮挡和视角后再决定；不明确时待核实 |
| 宣称耐盐雾若干小时但无附件 | 缺少证明不等于宣称为假，默认不列 P1 |
| 缺少尺寸表、OE 号、扭矩或组件清单 | 通常为资料缺项；不能凭缺项推定已有内容错误 |
| FAQ 重复问题或英文拼写错误 | 通常非 P1；只有造成关键使用/选型误导时按实际影响判断 |
| 当前目录 href 连续返回 404，未发现有效跳转 | 可列访问 P1；记录两次实时检查和目录 href 证据 |
| 旧 URL 404，但当前目录已经使用正常新页 | 退休旧 URL，删除旧地址 404 项；不新增“当前产品打不开” |
| 403、429、超时、登录页或反爬挑战 | 标为待复核，不能直接断言产品链接失效 |

## 证据要素

- URL、实际检查时间和页面位置。
- 两个互相矛盾的值及各自字段名称；不要省略“约”“可选”“典型值”等限定词。
- 图文矛盾注明图序/局部位置，并区分看过图片与仅验证图片可下载。
- 影响写具体：可能导致订错规格、错配接口、错误安装或无法进入当前产品页。
- 修改建议指出需同步的页面位置，不虚构厂家的正确参数。

`confirmed: true` 是审核者对上述证据的确认，不是抓取脚本自动生成的“正确性”标记。结构验证通过不证明技术判断成立。
