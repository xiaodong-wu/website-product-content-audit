# P1 判定规则：适用于各类产品的文字内容

P1 表示已确认、需要优先修正的内容问题，不代表产品质量或实物性能评级。本规则适用于实物、原材料、组件、软件及其他有产品详情页的产品，不固定品牌、行业参数或数值阈值。

仅核查产品标题、描述、属性、型号/SKU、规格参数、文字表格及详情正文。产品图片、图片内文字/OCR、图文对比、图片加载和画质问题均在范围外，不产生问题条目或覆盖缺口。

## 一、P1 必须满足的条件

每个 P1 同时满足以下条件：

1. **证据明确**：有当前页面可定位的原文、字段、文字表格或经复核的访问记录。不能凭行业印象、搜索摘要或缺少附件推定错误。
2. **比较对象一致**：冲突针对同一产品、规格、配置、版本和适用条件。先排除选配、不同系列、不同测量口径及不同使用阶段。
3. **存在具体影响**：能够说明错误如何导致选错产品、错算数量/价格、错配接口或系统、误用/误装，或误解材料成分、使用限制及实际交付内容。不能只写“影响体验/SEO/专业度”。
4. **没有合理解释**：页面其他文字未解释差异；信息不足时标记 `needs_review`，不以 `open P1` 导出。排除在范围外的图片问题不进入待核查队列。

文字自身已形成明确矛盾时，可以确认“页面表述冲突”，即使不知道哪一项是真值；修改建议要求厂家统一资料，不替厂家选择正确值。若要断言某值违反外部技术规则，必须引用与该型号、版本和条件匹配的厂家或权威资料，不能凭通用经验定论。

## 二、可判为 P1 的通用问题

下表给出候选类型；仍须逐项满足上述条件，不能按关键词自动升级。

| 类型 | 可成立的文字证据与影响 | 判定边界 |
| --- | --- | --- |
| 产品身份或型号错配 | 标题、属性和正文对同一 SKU 分别给出不同型号、规格或版本，使客户无法确定购买对象 | 区分系列名、父子 SKU、内部货号、替代型号及对比介绍；名称相似不等于复制错误 |
| 关键规格自相矛盾 | 同一条件下的尺寸、容量、功率、压力、温度、载荷、浓度或性能指标互不一致，影响选型或使用 | 区分额定/峰值、输入/输出、空载/负载、净值/毛值、总长/有效长、标称/实测及公差 |
| 单位或换算错误 | 原文中同一物理量的等价值换算明显不成立，或参数配错单位，改变规格含义 | 核对单位体系、数量级、分母和计量基准；不得将不同物理量直接比较，不统一设百分比误差阈值 |
| 数量、包装或计价冲突 | 每件数量、每包数量、总重、总容量、每套组成或计价单位无法按同一口径对应，导致错订或误算 | 区分单件/整包/组合、净重/含包装重、单价/总价、可选包装及近似值 |
| 材料、成分或结构冲突 | 同一部件/配方被写成互不相容的材料或成分，或“无某成分”与同页成分清单冲突，影响选型或使用限制判断 | 区分基材/涂层、外壳/内芯、不同部件、不同配方、可选材质及含量基准 |
| 适用范围或兼容性冲突 | 明确适用的型号、尺寸、接口、系统版本、配套设备或使用对象与同页排除项矛盾 | “可定制”“需转接器”“仅部分版本”须计入条件；不能仅凭未列出某型号判定不兼容 |
| 使用、安装或配置说明冲突 | 同一产品的不同文字步骤要求互斥的安装、连接、方向、配比、配置或先后顺序，可能直接造成误操作 | 区分使用阶段、可选安装法及不同配件；不能从图片猜测结构，也不凭缺少说明推断操作危险 |
| 使用条件或限制冲突 | 工作/存储条件、允许范围、维护条件、保质期或关键禁用说明之间明确冲突，影响实际使用决策 | 区分开封/未开封、工作/存储、短时/持续、不同环境及起算时间；不以行业习惯替代产品依据 |
| 核心功能或交付承诺冲突 | 标题或卖点明确承诺某功能、附件、容量、许可或服务，正文却说明不支持、不包含或需另购，且未限定不同版本 | 区分套装、选配、订阅档位、免费/付费功能及可见的条件说明；营销措辞夸张本身不足以判 P1 |
| 关键决策信息为空或无法确定 | 页面明确要求客户据某字段选型或订货，但该字段为空、错位、保留占位符，或缺少决定含义的单位/对象，其他文字也无法补足 | 必须指明哪个实际选择因此无法完成；没有完整参数表、证书附件或所有行业常见字段，不自动构成 P1 |
| 核心详情内容错贴或缺失 | 详情大段明确描述另一类产品，或页面宣称提供的关键规格区块为空，使标题所指产品无法被理解或选购 | 以可见文字核实，排除相关产品、举例和对比段落；简介较短、没有 FAQ 或文案风格普通不是 P1 |
| 排版、语言或表格错误改变含义 | 否定词、数值、小数点、型号漏写，或者参数表错行错列，已导致关键字段被错误理解 | 需引用受影响的文字关系；普通语法、空格、重复或不影响含义的格式问题不列 P1 |

## 三、按产品类型选择关键字段

以下是阅读线索，不是强制字段清单，也不是外部技术标准。只核查页面实际出现或明确用于选择/订货的字段，不能因为未列出某项就报错。未列举的产品按“身份—规格—数量—适用性—使用条件—交付内容”分析。

| 产品类型 | 优先交叉核对的文字字段 |
| --- | --- |
| 工业设备、机械、工具 | 型号、尺寸、额定能力、输入条件、安装方式、配套要求、工作范围、配置及附件 |
| 零部件、五金、汽车配件 | SKU、关键尺寸、接口/连接方式、适配型号、材质、单件/套装组成、安装说明 |
| 电子电气、仪器、储能产品 | 输入/输出参数、额定/峰值、容量与能量口径、接口/协议、测量条件、环境及版本 |
| 原料、化工、涂料、胶黏剂 | 等级、组成/浓度、计量基准、包装净含量、适用基材、配比、使用与存储条件 |
| 食品、营养及个人护理产品 | 配料/成分、净含量、每份/每包装、规格版本、适用对象、食用/使用说明及限制表述 |
| 服装、纺织、家具、家居用品 | 尺码/尺寸与计量口径、材料成分、颜色/款式选项、套装数量、适配范围、护理或组装文案 |
| 包装、耗材、定制产品 | 材料、尺寸、容量、每包数量、起订量、定制条件、配套兼容性、交付清单 |
| 软件、数字产品、订阅型产品 | 版本/档位、系统要求、功能限制、用户或设备数、许可范围、订阅周期、包含项目及另购条件 |

涉及认证、健康、环保、食品接触、阻燃或其他特殊宣称时，只核查已给文字之间的明确冲突；无证明附件不等于宣称虚假。不能把文案核查写成实物检测、认证鉴定、医学判断或法律合规结论。

## 四、通常不属于 P1 的情况

- 普通拼写、大小写、标点、空格、重复文案及不影响关键含义的翻译问题。
- SEO 标题长度、关键词密度、文案吸引力、内容篇幅、页面美观和通用转化建议。
- 没有附证书、测试报告、图纸、案例或完整参数表；缺项只有满足第二节“关键决策信息”条件才可能升级。
- 同一页面说明不同规格、可选配置、地区版本或不同工况，数值因此不同。
- 公称值、取整、公差、近似值或测量口径差异；必须先核实其解释空间。
- 无法访问的文字区块或抓取失败：记录范围缺口，不能凭空生成内容问题。
- 所有产品图片问题，包括图中文字与正文不符。即使图片可读取，也跳过。

边界检查示例：

| 情况 | 结论 |
| --- | --- |
| 同一包写每件 5 g、共 4 件，又明确写产品净重 60 g，无其他组成或近似说明 | P1 候选：数量与净重算术冲突；先排除漏列组成，不自行改成 20 g |
| 总长 43 mm、有效长 31.8 mm | 不据此列 P1：测量对象不同 |
| 同一型号的输入为 100 W、输出为 80 W | 不据此列 P1：物理意义不同 |
| 同一材质可选 A/B 两个版本，表中列了两种材料 | 不据此列 P1：已说明版本差异 |
| 声明不含某成分，当前同款成分表却明确列出该成分 | P1 候选：同款文字冲突，先排除配方版本差异 |
| 商品正文写一包 10 件，图片标注 12 件 | 不列：仅有图文冲突，图片不在范围内 |
| 页面未附某项认证证书 | 不列：缺少附件不能证明宣称为假 |
| 同一订阅档位的属性表写 10 个用户，购买说明写最多 5 个，未说明条件差异 | P1 候选：交付限制冲突 |

“P1 候选”需完成第一节的证据与影响判断后才能导出。

## 五、访问与新旧链接的独立判定

链接复核用于确保核查对象与来源有效，不包含产品图片链接检查。

- 当前目录实际 href 经两次不同时间的实时 GET 均返回 404/410，最新一次仍失败，可列访问 P1；记录当前目录和响应证据。
- 旧 URL 失效，但当前目录已使用可正常访问的同产品新地址：退休旧 URL，排除旧地址 404 项，不将新产品标成打不开。
- 当前目录仍指向失效旧地址而新页可用：问题是目录链接失效，明确可用新地址。
- 403、429、超时、登录页、浏览器挑战或只看到搜索缓存：访问未确认，不直接列 P1。
- HTTP 200 却显示错误页、首页或无关产品：人工核实正文与跳转；不可仅按 200 认定正常。当前导出器的 `access` 校验仅支持重复 404/410，其他访问异常应保留待复核说明，不伪造状态绕过校验。

## 六、问题证据与修改建议

每条导出的 P1 至少写清：

1. 当前产品 URL、核查时间、型号/版本及适用条件。
2. 原文所在的标题、属性字段、段落或规格表行；冲突问题列出双方原文和字段名称，保留“约”“可选”“最大”“典型值”等限定词。
3. 一句话问题：哪个字段在什么条件下与哪段文字冲突，或哪个关键决策字段确实无法确定。
4. 具体影响：客户可能在哪个选型、订货、安装、使用或交付判断中出错。不能仅重复“信息不一致”。
5. 可执行建议：需要同步修改哪些文字位置；正确值未获证实时请厂家依据批准资料确认，禁止猜填参数或要求追加图片检查。

同一根因在同页多处出现，合并为一条并列明所有位置；不同产品页分别记录。相互独立的错误分开记录。更新旧报告时，排除仅凭图片成立的问题；混合证据仅在文字证据本身足以成立时保留，不能将范围排除写成“已修复”。

`confirmed: true` 是审核者确认问题证据成立，不表示已验证产品实物或已确定正确参数。脚本只校验字段、关联和筛选，不替代以上语义判断。
